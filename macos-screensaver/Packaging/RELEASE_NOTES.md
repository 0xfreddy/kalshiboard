# KalshiBoardScreensaver

A macOS screen saver that turns live Kalshi binary markets into a fullscreen split-flap board.

## What's included

- Live Kalshi market data with API-provided titles and option labels
- YES/NO prices, probability bar, expiration date, and main category on each market
- Category and competition filters in Screen Saver Options
- Smoother tile scrambling and board transitions
- Branded DMG installer with custom background, thumbnail, and Kalshi volume icon

## Install

Download `KalshiBoardScreensaver.dmg`, open it, and copy `KalshiBoard.saver` to:

```text
~/Library/Screen Savers/
```

Then open System Settings > Screen Saver and select KalshiBoard.
