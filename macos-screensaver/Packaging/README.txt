KalshiBoardScreensaver

A live Kalshi split-flap market board for macOS.

Install KalshiBoard.saver by copying it to:

~/Library/Screen Savers/

Then open System Settings > Screen Saver and select KalshiBoard.

If macOS blocks the saver because it is unsigned or ad-hoc signed, allow it from
System Settings > Privacy & Security, or build/sign it with your Developer ID.

When replacing an older build, quit System Settings before copying the new saver.
If the old saver still appears, log out and back in or restart System Settings.

Use the Screen Saver Options button to choose:

- Dense: 30 x 10
- Balanced: 24 x 8
- Large Text: 18 x 6
- Dark or Light background
- Category filter
- Optional subcategory / competition filter

The board displays open binary Kalshi markets with the API-provided title,
expiration date, YES/NO prices, probability bar, and main category.
